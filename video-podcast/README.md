# JustBash video podcast

A roughly nine-minute Chinese video podcast explaining JustBash's parser,
interpreter, command registry, virtual filesystem, pipelines, and security model.

```bash
pnpm install --ignore-workspace
pnpm generate:voice
pnpm dev
pnpm render
```

Voiceover uses the built-in macOS `Tingting` voice. The editable script lives in
`src/content.ts`; regenerating the voiceover also regenerates the timeline and
caption JSON files.

## Commands

**Install Dependencies**

```console
npm i
```

**Start Preview**

```console
npm run dev
```

**Render video**

```console
npx remotion render
```

**Upgrade Remotion**

```console
npx remotion upgrade
```
